# expenses_tracker_project
 Personal Expense Tracker System

 Project Description

The Personal Expense Tracker System is a Python-based desktop application designed to help users manage and track their daily expenses easily.

The application allows users to add expenses, select categories, view total spending, delete individual records, and clear all expense data. It provides a simple and user-friendly graphical interface using Python Tkinter.

All expense records are stored in a local text file (expenses.txt), allowing users to access their saved records whenever they reopen the application.

 Features

* Add Expense: Add expenses by selecting a category and entering an amount.
* Expense Categories: Food, Rent, Travel, Shopping, Bills, Entertainment, Education, Health, and Other.
* View Expenses: Display all saved expenses in a table.
* Total Spending: Automatically calculate total expenses.
* Transaction Count: Display the total number of transactions.
* Delete Expense: Remove a selected expense.
* Clear All Data: Delete all saved expense records.
* Data Storage: Save expense information in a local text file.
* Input Validation: Prevent empty, invalid, or negative amounts.

Technologies Used

* Programming Language: Python
* GUI Library: Tkinter
* GUI Components: ttk
* Message Boxes: tkinter.messagebox
* File Handling: Python File Handling
* Operating System Module: os
* Data Storage: Text File (expenses.txt)

Installation and Setup

Step 1: Install Python

Download and install Python from:

https://www.python.org/downloads/

Step 2: Download the Project

Download or clone the project repository.

Step 3: Open the Project Folder

Open the project folder in VS Code or any Python IDE.

Step 4: Run the Application

Open the terminal and execute:

python main.py

Step 5: Start Managing Expenses

The Expense Tracker application will open, and you can start adding and managing your daily expenses.

1. Open the Expense Tracker application.
2. Select an expense category.
3. Enter the expense amount.
4. Click the Add Expense button.
5. View your expenses in the Recent Expenses section.
6. Select an expense and click Delete Selected to remove it.
7. Click Clear All Data to remove all records.
